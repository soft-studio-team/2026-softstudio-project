# appversion2 실행 가이드 (Mac)

이 폴더 구성
- `flutter_app/` : 앱 (더블탭 편집 / 팔로우 / 공유 리스트 / 정보 수정 포함)
- `parsing-engine/` : 파싱엔진 (수정 금지)
- `run_engine.sh` / `run_app.sh` : 실행 스크립트

## 중요
압축을 **바탕화면(iCloud)** 이 아닌 `~/Developer` 같은 로컬 폴더에 풀고 실행하세요.
Xcode 26에서 Desktop 경로면 codesign 255 오류가 날 수 있습니다.

## 1. 압축 풀기
```bash
mkdir -p ~/Developer
cd ~/Developer
unzip ~/Downloads/wishlist-appversion2.zip
cd wishlist-appversion2
```

## 2. 엔진 (터미널 1)
```bash
cd ~/Developer/wishlist-appversion2
./run_engine.sh
```

## 3. 앱 (터미널 2)
```bash
open -a Simulator
cd ~/Developer/wishlist-appversion2
./run_app.sh
```

또는:
```bash
cd ~/Developer/wishlist-appversion2/flutter_app
flutter pub get
flutter run -d "iPhone 17"
```

## 4. Firebase 연결 (로그인/계정/팔로우/계정별 위시)
자세한 단계는 `FIREBASE_SETUP.md` 참고.

요약:
1. Firebase Console에서 iOS/Android 앱 등록 (`com.softstudio.wishlist`)
2. Firestore 생성 + Authentication 이메일/비밀번호 ON
3. `flutterfire configure` 또는 `flutter_app/lib/firebase_options.dart` 키 채우기
4. `flutter run` 후 **회원가입**으로 계정 생성

## 5. 확인
회원가입/로그인 → 리스트 **더블탭** 편집 / **꾹 눌러 드래그** 순서 변경
→ 다른 계정 가입 후 내 친구에서 팔로우 → 공개 위시리스트 보기
→ 살까말까 공유 링크 → 마이페이지 정보 수정 / 로그아웃
