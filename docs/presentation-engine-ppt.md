# 가격 추출 엔진 — PPT 구성 + 멘트

A가 기능을 보여 준 뒤 이어받는다. 약 3분 30초.
슬라이드 3장. **대본은 슬라이드에 올리지 않는다.**
기능(공유하면 카드가 채워진다)은 앞에서 이미 말했으니, 여기서는 구현·검증·범위만 말한다.

화면: `docs/presentation-engine-slides.html`
방향키 또는 클릭으로 넘긴다.

## 1장. 구현 방식 — 1분 20초

**레이아웃:** 위 구조도 5칸 + 아래 추출 층 3칸 + 불렛 3개.

**슬라이드에 올릴 글**
- 리드: 서버에서 긁지 않습니다. 사용자 단말의 WebView가 페이지를 그린 뒤에 읽습니다.
- 공유 URL → ParsingBridge → 단말 WebView → ExtractLoop → 위시 카드
- 추출 층: 몰별 어댑터 / JSON-LD·OG / 화면 DOM
- 공유 담기는 이 한 길. 파이썬 서버는 앱에서 뺐습니다.
- 페이지가 멈춘 뒤 600ms를 기다리고, 값이 두 번 같으면 확정합니다.
- 확인한 몰은 전용 규칙으로만 읽고, 못 읽으면 다른 숫자로 우회하지 않습니다.

**멘트**

앞에서 보신 자동 채움이, 안에서 어떻게 돌아가는지만 말씀드리겠습니다.

예전에는 서버에서 페이지를 긁거나, 파이썬 파싱 API를 앱이 부르는 방식도 있었습니다.
지금은 그렇게 하지 않습니다.

공유로 URL이 들어오면, 사용자 휴대폰 안에 미리 붙여 둔 WebView가 그 상품 페이지를 엽니다.
페이지가 그려진 뒤에 정보를 읽습니다.
서버 IP로 막히는 몰이 많고, 가격이 자바스크립트로 늦게 붙는 페이지도 많아서, 사용자가 보던 그 페이지를 단말에서 그대로 읽는 편이 맞았습니다.

가격은 아무 숫자나 고르지 않습니다.
확인한 몰은 전용 규칙을 두고, 그 규칙으로 못 읽으면 다른 숫자의 가격으로 우회하지 않습니다.
쿠폰가, 회원가, 첫구매가는 정답으로 쓰지 않습니다.

페이지가 멈춘 뒤 0.6초를 더 기다리고, 같은 값이 두 번 나오면 확정합니다.
기본 제한은 12초입니다. 그전에 확정되면 바로 끝납니다.

## 2장. 어떻게 맞춰 봤나 — 1분

**레이아웃:** 숫자 4칸 + 불렛 3개.

**슬라이드에 올릴 글**
- Tab S7 · 실페이지 live compare
- 50몰 · 상품 슬롯 149개
- 3필드 · 이름·가격·이미지가 모두 같으면 MATCH
- 12초 · 기본 추출 제한
- 정답은 엔진이 아니라 브라우저로 연 화면. 쿠폰가·첫구매가는 정답이 아님
- 막히거나 기권한 몰은 실패로 세지 않음
- PR 28로 main에 들어감

**멘트**

검증은 Galaxy Tab S7에서 했습니다.
엔진이 읽은 이름, 가격, 사진을, 탭에서 직접 연 상품 페이지와 대조하는 live field compare입니다.
세 값이 모두 같으면 MATCH로 봤습니다.

카탈로그는 50몰, 상품 슬롯은 149개입니다.
정답은 엔진이 채운 값이 아닙니다. 화면에 보이는 조건 없는 판매가입니다.

이 코드는 풀 리퀘스트 28로 main에 들어가 있습니다.

## 3장. 어디까지 되고, 어디는 안 되나 — 1분 10초

**레이아웃:** 왼쪽 되는 쪽 + 패션 10몰 칩 / 오른쪽 안 되는 쪽 + 미지원 칩.

**슬라이드에 올릴 글**
- 되는 쪽: MATCH면 지원으로 말함. 회귀는 패션 인기몰부터. 못 읽으면 직접 입력.
- 칩: 에이블리, 무신사, 지그재그, 퀸잇, KREAM, 29CM, 4910, W컨셉, SSF샵, 올리브영
- 안 되는 쪽: 쿠팡 차단, 네이버 기권. Gap·SHEIN·NUGU는 통화. 엔진 전부 실패가 아님.
- 칩: 쿠팡, 네이버, 알리, 테무, Gap, SHEIN

**멘트**

지원으로 말하는 몰은, 이 대조에서 MATCH로 본 약 50곳입니다.

회귀할 때는 50곳을 매번 다 보기보다, 패션 인기몰을 먼저 봅니다.
에이블리, 무신사, 지그재그, 퀸잇, KREAM, 29CM, 4910, W컨셉, SSF샵, 올리브영입니다.

쿠팡은 접근이 막히고, 네이버는 카탈로그형이라 일부러 기권합니다.
알리나 테무는 아직 목록 밖입니다.
엔진이 전부 실패한 게 아니라, 지원 범위 밖의 문제입니다.

짧게 한 가지만 더 말씀드리겠습니다.
에이블리처럼 한 페이지에서 화면이 바뀌거나, m이랑 mobile처럼 주소가 갈리는 몰은
로드가 끝나기 전에 읽으면 값이 비었습니다.
같은 사이트 안에서 맞춘 뒤, 그려질 때까지 기다리고 읽도록 맞춰 갔습니다.

여기까지가 카드를 어떻게 채우는지입니다.
